# GALATEA 🌌

GALATEA es un proyecto web desarrollado durante el curso de **Creación y Publicación de Páginas Web**.

La web presenta un universo ficticio formado por diferentes mundos, especies y culturas, combinando contenido creativo con artículos relacionados con la astronomía, la exploración espacial y la posibilidad de vida extraterrestre.

El proyecto ha sido desarrollado con **HTML5, CSS3 y JavaScript**, sin utilizar frameworks.

---

## 🌍 Mundos de GALATEA

El universo está formado actualmente por cuatro mundos principales:

| Mundo | Especie |
|---|---|
| Lumia | Lumienses |
| Krynar | Krynerios |
| Layen | Layenses |
| Portha | Portenses |

Cada mundo tiene características propias y las especies pueden explorarse mediante carruseles interactivos.

---

## 📄 Estructura de la web

La web incluye:

- **Inicio:** presentación de GALATEA y acceso a las principales secciones.
- **Mundos:** presentación de Lumia, Krynar, Layen y Portha.
- **Especies:** carruseles interactivos con información e imágenes.
- **Blog:** artículos relacionados con astronomía y vida extraterrestre.
- **Proyecto:** explicación del concepto de GALATEA.
- **Contacto:** formulario demostrativo.
- **Aviso legal, privacidad y política de cookies.**

El proyecto cuenta además con cuatro artículos:

- Alien vs. extraterrestre.
- Vida en otros planetas.
- Cómo detectar vida extraterrestre.
- Cómo sería viajar a un planeta con dos lunas.

## 💻 Tecnologías utilizadas

### HTML5
Utilizado para crear la estructura y contenido de las páginas.

### CSS3
Utilizado para el diseño visual y la adaptación a diferentes tamaños de pantalla.

Se han utilizado, entre otras técnicas:

- Flexbox
- Grid
- Media queries
- Diseño responsive
- `clamp()` para tamaños adaptables

### JavaScript
Se utiliza para añadir interactividad a la web:

- Menú hamburguesa en dispositivos móviles.
- Carruseles de especies.
- Comportamiento del formulario de contacto.
- Mejoras de accesibilidad.

### Google Fonts
La tipografía **Orbitron** se utiliza como parte de la identidad visual de GALATEA.

---

## 📱 Diseño responsive

GALATEA está preparada para visualizarse en:

- Ordenadores
- Tablets
- Teléfonos móviles

La navegación cambia a un menú hamburguesa en pantallas pequeñas y el contenido se adapta mediante media queries.

---

## ♿ Accesibilidad

Durante el desarrollo se han incorporado diferentes mejoras de accesibilidad, entre ellas:

- Textos alternativos en imágenes.
- Foco visible durante la navegación con teclado.
- Etiquetas ARIA en controles interactivos.
- Navegación mediante teclado.
- Tamaños de texto adaptados para facilitar la lectura.
